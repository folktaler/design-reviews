Cats of Kochi — two typefaces, one decided

Labelled catsofkochi-airbnb-design-system-2026-08-09. 13 pages, one shared faces file per font family, no build step and no JavaScript. Only 2 of the 13 kits show the current typeface. The other 11 still show a serif that has been retired — read the gap below before judging any type on this site.

Known gaps — read this before reviewing

  • ⭐ Eleven of the thirteen kits show a serif body the current direction has already retired. The owner decided, 9 August 2026: Cats of Kochi is Figtree, all-sans — no second family. Only system.html and venue.html carry that decision today. The other eleven (homepage, index_browse, today, itinerary, venue_page, venue_pages, told_page, told_page_listing, answer_page, controls, type_before_after) are Guardian-era and still run Noticia Text, awaiting a rebuild. Do not spend a review pass critiquing a typeface that is already gone — everything else about these pages (layout, spacing, component structure) is still live and worth reviewing.
  • The Android fallback arm is unverified by rendering. Fallback metrics for Noto Serif and Roboto are derived from @capsizecss's published metrics, not measured on an Android device — nobody here has one to measure against.
  • This site renders in standards mode; the Claude Design preview does not. Every kit published there reports document.compatMode: "BackCompat" (quirks) because that host's serve wrapper injects markup ahead of the doctype — not our markup, not fixable there. Where the two differ, trust this one.
