# Note

**The publisher speaking about the piece, rather than the author writing it.**

## Markup

```html
<div data-note>
  <span data-note-label>What this list does not yet show</span>
  <p>Fifteen stories are listed. The live index reports Page 1 of 6, so the real
    archive is closer to seventy.</p>
</div>
```

## Rules

- ⛔ Not a Correction. A correction says we published something untrue about a named person; this is context.

## Styling

There is no JavaScript component to import. Style with the system's tokens and
attributes: the `data-*` landmark above is the styling hook AND the contract a
check reads. Never rename it to a class of convenience.
