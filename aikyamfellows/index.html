Design review · 8 August 2026

aikyam fellows

A Guardian-faithful design system for a not-for-profit that publishes profiles of people doing social-impact work. Thirteen pages, one system, no build output per page, no JavaScript, no webfont.

For reviewers

Every page is self-contained — all component CSS is inlined, so a page can be opened, saved or handed to a model on its own. ⚠️ That is a property of these REVIEW KITS, not of the shipped site: the real site runs on Ghost with one cached stylesheet.

The reasoning is in the CSS. Every measurement, rejected alternative and reversed decision is written where the rule is — see source/system/. If a rule looks arbitrary, the reason is in the comment above it. Reversals are kept, not deleted: dark mode was decided three times and the history is why it stopped being re-litigated.

⛔ Known gaps — please do not report these as findings. There are no photographs (73 image placeholders), no email address, no giving amounts, no partner logo files, and no file sizes on the compliance documents. Each is a fact only the organisation has.

⚠️ One measured gap. The column is 576px because that is the widest width where Georgia, Charter and Palatino all stay under 65 characters a line. Cambria — what Windows readers get — could not be tested and is narrower, so it may exceed the gate. If you are on Windows, that is the single most useful thing you can check.
