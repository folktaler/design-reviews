Clubs

Three clubs run at aikyam space, all free and all in Malayalam. You do not need to sign up. Come to the space at the time below and say who you are.

Seats are limited, and preference goes to low-income and under-served households from Fort Kochi, Mattancherry and nearby areas.

This note read “Sunday 9 August. Every club is closed on Mondays.” — so the page said open and closed in adjacent sentences and never answered the question the reader had, which is what is on today. ⭐ The lesson is about the component, not the copy. “Three” had been written into a heading, a lede and an intro sentence, so a true count became a design constant and the layout quietly asserted something only the content should say. The section now holds any number of clubs — the grid is auto-fill, nothing counts them, and adding a sixth is a content edit with no CSS change.

⛔ Never write a count into a heading. If a number is worth showing, it is worth deriving from the thing being counted.

Stitching, step by step

The stitching club runs in four levels. You start wherever you are and move when you are ready — nobody is timed.

LevelWhat you learn
1 · SaverRepair old or damaged clothes and everyday household items.
2 · MakerUp-cycle fabric leftovers from boutiques into bags and pouches; learn screen printing to add value.
3 · Tiny EntrepreneurEarn ₹2,000–5,000 a month from products you make and sell.
4 · Role ModelGet support to start your own stitching club near where you live.

So they are now club rows like any other, with the unknown named in the slot where the time goes and the action changed from “Just turn up” to “Write to us first”, because turning up for a session whose time nobody published is advice that strands somebody.

This is the same grammar as the empty “Coming up”: the heading survives and the missing value is replaced by the reason, never by silence. A club that exists and is invisible on the schedule page is worse than one shown as incompletely known — the first looks like it does not exist.
