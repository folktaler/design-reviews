⚠️ Reviewer notes — not page copy

⛔⛔ 1. The "different sizes" defect was a bug of mine, not a layout choice

Every photograph was rendering 1200px tall instead of 288px, making photo cards 1300px against 88px for a photo-less one — a 15× difference. ⭐ aspect-ratio: 4/3 was computing correctly and being ignored, because the height="1200" attribute I added to stop the feed reflowing becomes a presentational height, and aspect-ratio only sizes a box when the other axis is auto.

⛔⛔ So the fix for one real defect silently created a worse one, and both measurements looked right — computed style reported 4 / 3 and cover, exactly as intended. ⭐ Only the rendered height showed it. Fixed with height:auto; the attributes stay, so reflow is still prevented.

⭐⭐ 2. Single column, so "equal heights" is not a problem to solve

A photo-less entry in a multi-column grid always looks like a hole, because it has side-by-side neighbours to be unequal with. ⭐ In a single column there are no neighbours, so the question cannot arise. “This is better for the home page” and “the cards are all different sizes” turned out to be the same observation.

⚠️ An equal-height grid was built and rejected. It equalised perfectly — tallest 388, shortest 388 — and my own metric told me it cost only 8px of whitespace, which was wrong: I measured the card against its text elements, and the headline was itself flex:1, so the box had already absorbed the empty space. ⭐ A screenshot settled it in one look — headlines adrift in large empty boxes. Equal heights were geometrically achievable and looked worse than the problem.

⭐ 3. The excerpt is what makes a photo-less entry look deliberate

Measured on the live 195: shortest body 82 characters, median 227, longest 531. ⭐ Cut at 300 and 83% show in full — the card simply ends. Only the longest sixth is trimmed, which is exactly when a “more” link is informative rather than decorative.

⛔ So the trade I flagged — “equal heights cost you the excerpt” — does not exist. My “60 to 3,400 characters” came from the day-level extraction and died with it; per-activity bodies are a fifth of that. ⭐ And a photo-less entry now has a real paragraph where the photograph would have been, so it looks deliberate because it is full.

⛔ 4. No "read more" — and the reason is a ruling he already made

The card is already a link, so “read more” is a second affordance for the same action — and he objected to whole sections being clickable, which produced the grow the link, do not extend it over things that are not the link fix.

⭐ So the photograph and the headline are both links to the same entry, and nothing else is. That is Airbnb's own pattern, and it honours his objection exactly: the excerpt stays selectable, because nothing is laid over it. ⚠️ The cost, stated: a reader must aim at the headline or the picture rather than anywhere in the block. With the headline padded to 44px that is a comfortable target and the photograph is a large one.

⭐ 5. The quotation entry uses the review form, not a card

12 May carries an entry that is nothing but Rohit Sharma's sentence. ⛔ A card frames a thing that happened; a quotation is somebody speaking. ⭐ It uses the same component as the residents' testimonials — no container, no border, radius 0 — and the headline never borrows its words.

⚠️ Four of these twelve are not club sessions — a visiting organisation, a researcher's survey, a one-to-one fundraising conversation, and this quotation. The extraction is right to include them; whether they belong on the front page is an editorial question nobody has been asked.
