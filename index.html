Design reviews

Work in progress, published so it can be reviewed on a real device and by people and models who are not on this machine. Folders are removed as each project finishes.

  • aikyam fellows
    A Guardian-faithful design system for a not-for-profit publishing profiles. 13 pages, 34 components, no build step.
  • Cats of Kochi
    An Airbnb-faithful design system for a travel guide to Fort Kochi and Mattancherry. 13 pages, one shared faces file per font family, no build step.
  • Open Collective
    The design system behind a fork of Open Collective, with tokens copied from the platform's own stylesheet rather than matched by eye. 4 pages, one shared tokens file, no build step.
  • Finish the Line
    A screen system for a 60-second phone game built from Friends dialogue. 3 pages, one shared tokens file, no build step. Vendored controls are drawn as plain-CSS stand-ins; the logo is four concepts, not yet chosen.
  • aikyam space
    An Airbnb-faithful design system for a community room in Fort Kochi (aikyam.space). 5 pages, one shared tokens file, no build step. Proposes replacing the homepage's diary post with a real schedule sourced from the live site's own club listings.
